# ProbTalk3D as a service

Speech in, 3D talking face out. Upload or record speech, choose a speaker style,
emotion, intensity and temperature, and get a rendered animation plus the FLAME
parameters (.npy). Course project for ITCS 6166 (UNC Charlotte), built on
ProbTalk3D (Wu et al., ACM SIGGRAPH MIG 2024) and the authors' pretrained weights.

Code: https://github.com/jsdmhash/ProbTalk3D (folder `ours/`).
