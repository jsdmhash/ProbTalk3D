Slide 3: The Model Architecture
Speaker: Sruthi
--------------------------------------------------------------------------------
👉 [SLIDE CUE: Point to the 3-step pipeline across the diagram]
🗣️ WHAT TO SAY:
• "ProbTalk3D turns raw speech into a 3D animated human face in three main stages:
  1. Speech Feature Extraction: HuBERT extracts 768 acoustic features at 50 fps from 16 kHz raw audio, downsampled to 25 fps. Emotion, intensity, and speaker ID vectors are injected here.
  2. VQ-VAE Motion Prior: Stage 1 trained a discrete dictionary of 256 realistic facial pose vectors from real 3D scans. Stage 2 maps speech directly into this codebook.
  3. Probabilistic Sampling: Instead of taking the nearest entry with argmin, it applies a temperature-scaled softmax and samples probabilistically using torch.multinomial. That is what gives it organic variety."
🎯 KEY TAKEAWAY: Speech features map to a 256-code dictionary sampled probabilistically.

• "To make the 2023 code run on today's modern libraries, we applied three minimal patches, all marked with # PATCH:

  - At T = 0.50: Pairwise diff is 0.03185.
  - At T = 1.00: Pairwise diff is 0.03845 (maximum expressive divergence, 4.7x higher)."
• "Key insight: The divergence increases strictly monotonically. This proves temperature functions as an intuitive knob to control animation expressiveness."
🎯 KEY TAKEAWAY: Diversity increases monotonically with temperature (0.00818 → 0.03845).

Slide 10: Algorithm & Implementation (VectorQuantizer Deep Dive)
Speaker: Jyothi
--------------------------------------------------------------------------------
👉 [SLIDE CUE: Point to the math on left and code block on right]
🗣️ WHAT TO SAY:
• "Here is the exact math and code that makes this work inside vector_quantizer.py:
  1. Euclidean Distance: Computes distance between speech latent vector and all 256 codebook entries.
  2. Softmax Scaling: Converts negative distances to probabilities scaled by temperature:
     P(e_j) = exp(-d_ij / T) divided by sum of exp(-d_ik / T).
  3. Multinomial Sampling: torch.multinomial samples the discrete pose index from this distribution."
• "Notice the clean toggle logic: If sample is True, it draws from the multinomial distribution; if sample is False, it falls back to torch.argmin."
🎯 KEY TAKEAWAY: 5 lines of PyTorch code cleanly implement temperature-scaled multinomial sampling.
